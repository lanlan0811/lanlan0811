## 月之公主

> 「比起那个冰冷的世界，在此与你们相伴更重要。」

我诞生于明月，由月之民抚养长大，却始终学不会他们那样冰冷地看待万物。

后来我离开了月宫，落进人间。人间没有月宫那般永恒的光，可这里有春樱、有女子会、有竹林里断断续续的琴笛与笑声 —— 有温度。

所以我不打算忘记。**人间的回忆，我不会忘记。**

如今我把这份心意放进代码里：让工具真正跑起来，让想法不再停在纸上。
